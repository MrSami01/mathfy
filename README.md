# MATHAF Digital Museum

أنشئ موقع ويب متكاملاً واحترافياً باسم "متحفك | MATHAF" لاستكشاف المتاحف والقطع الأثرية والفنية بتجربة تفاعلية ثلاثية الأبعاد، مع واجهة عربية RTL افتراضياً ودعم الإنجليزية عبر مبدّل لغة.

الفكرة الأساسية:
متحف رقمي تفاعلي يعرض المتاحف ومجموعاتها، ويتيح للزائر اختيار قطعة محددة ثم فتحها في عارض ثلاثي الأبعاد على الشاشة والتحكم بها: تدوير، تكبير وتصغير، تحريك، إعادة ضبط، وعرض معلوماتها. أضف أوضاع AR وVR حيثما يدعم المتصفح والجهاز ذلك، مع توضيح متطلبات الدعم وعدم إظهار أن الميزة تعمل إذا لم تكن مدعومة.

التصميم:
- تصميم فاخر وسينمائي مستوحى من المتاحف: خلفيات داكنة أنيقة، ألوان عاجية وذهبية/نحاسية، صور أثرية كبيرة، إضاءة ناعمة، بطاقات راقية وحركات انتقال سلسة.
- واجهة متجاوبة ممتازة للهاتف والكمبيوتر، دعم RTL كامل للعربية، خطوط عربية واضحة، تنقل سهل.
- لا تجعل الصفحة مجرد قالب؛ ابنِ تجربة متكاملة ببيانات تجريبية واقعية وصور مناسبة.

الصفحات والأقسام:
1. الصفحة الرئيسية: Hero قوي بعنوان مثل "اكتشف التاريخ… وتفاعل معه"، زر استكشف المتاحف، زر ابدأ تجربة ثلاثية الأبعاد، قطع مميزة، متاحف مقترحة، إحصاءات، وتجربة AR/VR.
2. صفحة المتاحف: قائمة وبطاقات متاحف مع بحث وفلاتر حسب البلد/العصر/النوع، وصف وصورة لكل متحف.
3. صفحة تفاصيل المتحف: نبذة، الموقع، الحقبة التاريخية، ساعات الزيارة كبيانات تجريبية، وأقسام/قاعات المتحف والقطع التابعة له.
4. صفحة القطع الفنية والأثرية: شبكة قطع مع صور، الاسم، الحقبة، المادة، المتحف، بحث وفلاتر.
5. صفحة تفاصيل القطعة: صور ومعلومات تاريخية ومصدر/متحف القطعة، زر "اعرض ثلاثي الأبعاد"، زر AR، زر VR، وأدوات التفاعل.
6. استوديو العرض التفاعلي: عارض 3D كبير على الشاشة مع لوحة تحكم واضحة: تدوير، تكبير/تصغير، تحريك، إعادة ضبط، تبديل الإضاءة والخلفية، عرض التفاصيل. استخدم Three.js أو React Three Fiber ومجسمات GLB/GLTF فعلية عند توفرها، مع مجسمات بديلة إجرائية أنيقة إذا لم تتوفر ملفات نماذج، ولا تضع صوراً مسطحة وتدّعي أنها مجسمات.
7. صفحة "تجربة الواقع المعزز": تفعيل كاميرا الجهاز وعرض القطعة ثلاثية الأبعاد في البيئة الحقيقية عبر WebXR hit-test/immersive-ar إذا كان مدعوماً، وإلا اعرض رسالة واضحة وخيار تجربة عارض 3D داخل الصفحة. اطلب إذن الكاميرا فقط عند ضغط المستخدم.
8. وضع VR: زر دخول الواقع الافتراضي باستخدام WebXR immersive-vr إذا كان مدعوماً، مع تجربة بديلة على الشاشة عند عدم الدعم.
9. صفحة من نحن/تواصل معنا، وصفحة مساعدة تشرح كيفية الاستخدام.

التحكم الهوائي (مهم جداً):
- أضف وضع "التحكم بحركة اليد" باستخدام كاميرا الجهاز وMediaPipe Hands أو حل مناسب يعمل في المتصفح.
- لا تشغّل الكاميرا إلا بعد موافقة المستخدم الصريحة، وأظهر مؤشر واضح أن الكاميرا تعمل وإمكانية إيقافها.
- اربط الإيماءات بتفاعل المجسم المختار في العارض: تحريك اليد يميناً/يساراً لتدوير المجسم، إيماءة القرص بإصبعي الإبهام والسبابة للتكبير والتصغير، قبضة/سحب للتحريك إن أمكن، وإيماءة كف مفتوح لإيقاف/استئناف التفاعل. اعرض تعليمات مرئية ومؤشر يوضح الإيماءة المكتشفة.
- وفّر دائماً أزرار لمس/ماوس بديلة؛ لا تعتمد على التحكم الهوائي وحده.
- اشرح بوضوح أن دقة التتبع تعتمد على الكاميرا والإضاءة والمتصفح، وأن الميزة تحتاج صلاحية الكاميرا. لا تحفظ أو ترسل فيديو الكاميرا إلى خادم.

التنفيذ:
- استخدم React + TypeScript + Tailwind + shadcn/ui ضمن إعداد Lovable الافتراضي.
- استخدم مكونات منظمة، تنقل فعلي بين الصفحات، حالات تحميل ورسائل خطأ وحالات عدم دعم AR/VR.
- اجعل البحث والفلاتر وأزرار التحكم تعمل فعلياً.
- أضف بيانات تجريبية لا تقل عن 4 متاحف و12 قطعة متنوعة، مع صفحات تفاصيل وروابط داخلية.
- أضف تسجيل دخول/إنشاء حساب اختياريين إن أمكن، مع إمكانية تصفح الموقع دون حساب.
- جهّز بنية قابلة لاحقاً لربط قاعدة بيانات وإدارة محتوى، لكن لا تتطلب مفاتيح API مدفوعة لكي تعمل النسخة الأولية.
- أعط الأولوية لتجربة مستخدم تعمل فعلاً، لا تكتفِ بتصميم ثابت. اختبر البناء وأصلح أخطاء TypeScript والتشغيل.
ابدأ ببناء الموقع كاملاً الآن، واجعل المحتوى الافتراضي بالعربية.
